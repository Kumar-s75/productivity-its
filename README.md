# Prod-tracker

A personal productivity and life-tracking app for iOS. Log your mood, build habit stacks, capture quick thoughts, and track projects — with GitHub, Vercel, and GoDaddy integrations for developers.

## Features

- **Daily Focus** — set a single intention for the day
- **Mood Tracking** — log mood entries with context snapshots
- **Habit Stacks** — build and track recurring habits
- **Quick Capture** — voice and text rapid-entry for thoughts
- **Projects & Milestones** — lightweight project tracker
- **Gamification** — achievements and streaks to keep momentum
- **Developer Integrations** — GitHub activity, Vercel deploy status, GoDaddy domain health
- **Data Export** — export your full history
- Spotlight search, dynamic quick actions, TestFlight-aware features

## Tech Stack

- Swift · SwiftUI
- SwiftData
- GitHub API · Vercel API · GoDaddy API
- AVFoundation (voice capture)
- UserNotifications

## Requirements

- iOS 17.0+
- Xcode 16+

## Setup

1. Clone and open `Pulse.xcodeproj`
2. Build and run — connect integrations from the settings screen
